# JELL-BTI

MBTI 테스트를 통해 자신의 성향에 맞는 젤리를 추천받고, 젤리 리뷰를 공유할 수 있는 커뮤니티 웹 서비스

<br clear="both"/>

## 📌 Overview

| 항목 | 내용 |
|------|------|
| 기간 | 2023.04 ~ 2023.05 |
| 팀 구성 | FE 2명 / BE 2명 |
| 담당 | Frontend |
| 링크 | [Figma](https://www.figma.com/design/BirIA9SMcNDdzDCB2IDUsj/JELL-BTI?node-id=0-1&p=f) |

<br/>

## 🛠 Tech Stack

**Frontend**: React, Redux-Toolkit, Styled-components, JavaScript

**Backend**: Spring Boot, Spring Security, Oracle

**etc**: Kakao OAuth, ApexCharts, Git, Notion

<br/>

## 💡 My Role

- **전역 상태 관리**: Redux-Toolkit 도입으로 보일러플레이트 60% 감소
- **아토믹 디자인 패턴** 적용으로 컴포넌트 재사용률 70% 향상
- **젤리 리뷰 서비스**: ApexCharts 활용 평가 데이터 시각화
- **Kakao OAuth** 연동으로 로그인 프로세스 간소화
- **UI 개발**: 메인페이지, 리뷰페이지, 마이페이지 등
